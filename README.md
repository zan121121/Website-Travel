# Kualanamu Travel

Website satu halaman (HTML + CSS, tanpa JavaScript).

## Struktur
- `index.html` : halaman utama
- `assets/css/style.css` : semua gaya dan animasi
- `assets/img/` : foto mobil, pesawat, dan tempat wisata

## Deploy ke GitHub Pages
1. Push semua isi folder ini ke repository GitHub (index.html harus di root).
2. Buka Settings > Pages, pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu Save.
3. Situs online di `https://USERNAME.github.io/NAMA-REPO/`.

## Ubah nomor WhatsApp / template pesan
Nomor dan template ada di link `wa.me` di `index.html` (cari `wa.me/`). Teks pesan memakai format URL-encoded.
